# Optional Dependencies for Conformity

# These dependencies are optional and may require building from source.
# The core Conformity functionality works without them.

# ============================================================
# Color Management (Optional)
# ============================================================

# PyOpenColorIO>=2.3.0
#
# NOTE: PyOpenColorIO often doesn't have pre-built wheels for all platforms,
# especially Apple Silicon (ARM64) Macs.
#
# Installation Options:
#
# Option 1: Build from source (recommended)
# ----------------------------------------
# brew install opencolorio  # macOS with Homebrew
# pip install PyOpenColorIO
#
# Or on Linux:
# sudo apt-get install libopencolorio-dev  # Ubuntu/Debian
# pip install PyOpenColorIO
#
# Option 2: Use conda
# -------------------
# conda install -c conda-forge opencolorio
#
# Option 3: Skip color management
# -------------------------------
# Conformity will work without PyOpenColorIO, but color management
# features will be disabled. The system will gracefully handle the
# missing dependency.
#
# To verify installation:
# python -c "import PyOpenColorIO as ocio; print(f'OCIO version: {ocio.__version__}')"
